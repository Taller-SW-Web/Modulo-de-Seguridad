Luis David conserva dos; cada otro estudiante tiene una. SPEC-17/SPEC-18 son responsabilidad técnica adicional de Sergio, sin novena épica académica.

Cada dueño realiza interfaz, backend, datos, validaciones, eventos, pruebas y demostración. Revisiones y dependencias no transfieren capas. El panel administrativo integra bloques completos de distintos dueños; véase [responsabilidades](../../docs/responsabilidades.md).

La primera versión de cada ficha es un **objetivo para Hito 3**, condicionado a bloqueos. No adelanta automáticamente todo el alcance del curso ni acredita aprobación contractual. Ventas aún debe confirmar la propuesta del Hito 3 (INT-05). Marketplace conserva alcance general.
